# HOW TO CREATE YOUR .env FILE
#
# 1. Copy this template:
#      cp .env.template .env
#
# 2. Fill in your real Apple Developer credentials. You need a
#    "Developer ID Application" certificate (for distributing outside the
#    Mac App Store) — this is DIFFERENT from a Mac Development certificate.
#
# 3. The .env file is gitignored and MUST NEVER be committed.
#
# ── Where to get each value ──────────────────────────────────────────
#
# APPLE_ID
#   The email address on your Apple Developer account.
#
# APP_SPECIFIC_PASSWORD
#   Sign in at https://appleid.apple.com → "Sign-In and Security" →
#   "App-Specific Passwords" → Generate. Required because notarytool
#   cannot use 2FA interactively.
#
# TEAM_ID
#   https://developer.apple.com/account → "Membership Details" →
#   "Team ID" (a 10-character string like ABCDE12345).
#
# SIGNING_IDENTITY
#   The exact name of your "Developer ID Application" certificate as it
#   appears in Keychain Access. Format:
#     Developer ID Application: <Your Name or Company> (<TEAM_ID>)
#   You can list yours with:
#     security find-identity -v -p codesigning | grep "Developer ID"
#
# ── Example .env contents (DO NOT commit these real values) ─────────
#
# APPLE_ID=you@example.com
# APP_SPECIFIC_PASSWORD=abcd-efgh-ijkl-mnop
# TEAM_ID=ABCDE12345
# SIGNING_IDENTITY=Developer ID Application: Your Name (ABCDE12345)
